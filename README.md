Responsive Shopping Cart

A modern, responsive, and interactive shopping cart website built with HTML5, CSS3, and JavaScript.

This project demonstrates a complete frontend shopping experience where users can browse products, add items to their cart, update quantities, remove products, apply discounts, and view an automatically calculated order summary.

✨ Features
📱 Fully responsive design
🛍️ Modern e-commerce UI
🛒 Add to cart
➕ Increase product quantity
➖ Decrease product quantity
🗑️ Remove products
❤️ Wishlist/favorite button
🔢 Dynamic cart counter
💰 Automatic price calculation
🎟️ Discount/coupon system
🚚 Shipping calculation
🧾 Order summary
💾 LocalStorage support
🔄 Cart persistence after refresh
🌙 Dark/light mode
✨ Smooth animations
📱 Responsive mobile navigation
⬆️ Back-to-top button
